第一步：初始化核心寄存器（确保屏幕能正常工作）
// 1. 关闭显示（初始化前先关，避免乱码）
START → 0x78 → 0x00 → 0xAE → ACK
// 2. 设置显示时钟分频比/振荡器频率（默认配置，稳定显示）
START → 0x78 → 0x00 → 0xD5 → ACK → 0x80 → ACK
// 3. 设置多路复用率（128x64屏固定为0x3F，对应64行）
START → 0x78 → 0x00 → 0xA8 → ACK → 0x3F → ACK
// 4. 设置显示偏移（无偏移，默认0x00）
START → 0x78 → 0x00 → 0xD3 → ACK → 0x00 → ACK
// 5. 设置显示起始行（从第0行开始，默认0x40）
START → 0x78 → 0x00 → 0x40 → ACK
// 6. 开启电荷泵（关键！不开启屏幕不亮，参数0x14=开启）
START → 0x78 → 0x00 → 0x8D → ACK → 0x14 → ACK
// 7. 设置内存寻址模式（水平寻址，方便连续发数据）
START → 0x78 → 0x00 → 0x20 → ACK → 0x00 → ACK
// 8. 设置段重映射（左右正常显示，0xA1=反向，0xA0=正向，按需选择）
START → 0x78 → 0x00 → 0xA1 → ACK
// 9. 设置COM输出扫描方向（上下正常显示，0xC8=反向，0xC0=正向，按需选择）
START → 0x78 → 0x00 → 0xC8 → ACK
// 10. 设置COM引脚硬件配置（128x64屏固定0x12）
START → 0x78 → 0x00 → 0xDA → ACK → 0x12 → ACK
// 11. 设置对比度（默认0xCF，亮度适中，可调整0x00~0xFF）
START → 0x78 → 0x00 → 0x81 → ACK → 0xCF → ACK
// 12. 设置预充电周期（默认配置0xF1）
START → 0x78 → 0x00 → 0xD9 → ACK → 0xF1 → ACK
// 13. 设置VCOMH deselected电平（默认0x30）
START → 0x78 → 0x00 → 0xDB → ACK → 0x30 → ACK
// 14. 恢复RAM内容显示（不强制全亮，按数据显示）
START → 0x78 → 0x00 → 0xA4 → ACK
// 15. 正常显示模式（非反色，0xA6=正常，0xA7=反色）
START → 0x78 → 0x00 → 0xA6 → ACK

第二步：设置显示范围（全屏幕覆盖：列 0~127，页 0~7）
// 1. 设置列地址范围（0x21=列地址命令，参数0x00=起始列，0x7F=结束列）
START → 0x78 → 0x00 → 0x21 → ACK → 0x00 → ACK → 0x7F → ACK
// 2. 设置页地址范围（0x22=页地址命令，参数0x00=起始页，0x07=结束页，共8页）
START → 0x78 → 0x00 → 0x22 → ACK → 0x00 → ACK → 0x07 → ACK

第三步：发送全亮数据（1024 字节 0xFF，填满整个屏幕 RAM）
屏幕分辨率 128x64，共 8 页（每页 8 行），每页需发送 128 字节数据，8 页 ×128 字节 = 1024 字节，全部发送 0xFF（表示像素点亮）：
START → 0x78 → 0x40 → 0xFF → ACK → 0xFF → ACK → ...（共发送1024次0xFF）→ STOP

第四步：开启显示（最后一步，点亮屏幕）
START → 0x78 → 0x00 → 0xAF → ACK → STOP
